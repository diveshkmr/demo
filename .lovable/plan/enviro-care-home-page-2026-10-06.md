# Enviro Care Home Page

## Goal
Build one premium, responsive home page for Enviro Care using the supplied copy and images, with no additional pages or backend features.

## What I’ll build
- A slim contact bar and sticky navigation with a working mobile menu.
- A concise image-led hero focused on Dubai cleaning and technical services.
- The supplied Who We Are, five-stat, six-product, Why Choose Us, three-step process, contact banner, and footer sections.
- A trusted-client row only if genuine uploaded client logos are available.
- Clickable phone, email, quote, and contact actions that stay within this one-page experience.

## Visual direction
- Premium UAE corporate presentation using Enviro Care’s green identity, off-white surfaces, charcoal typography, subtle borders, and restrained motion.
- Supplied photography only, matched to each service and optimized through stable responsive crops.
- Desktop, tablet, and 390px mobile layouts with no overflow.

## Technical details
- Keep the existing TanStack Start setup and implement the home page at `/`.
- Define the page’s semantic colors, typography, spacing, and motion in the global design system.
- Copy the uploaded images into `public` and reference them with direct paths, as requested.
- Add unique home-page metadata and preserve all supplied business facts verbatim.
- Verify the rendered page at desktop and mobile sizes, including menu behavior and contact links.

## Scope boundary
No About, Products, Gallery, Contact, or Quote pages; no database, login, forms, APIs, or generated/stock imagery.
